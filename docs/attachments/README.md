# DEVLOG から参照する添付

DEVLOG の本文から参照するファイルのうち、本文に貼るには長いものを置く。

**`/tmp` に置かない。** 一度 DEVLOG から `scratchpad/` (セッション固有の
`/tmp` 以下) を参照していたが、セッションが終われば消える場所なので
参照が切れる。「後から参照できるように」が目的の記録で、
参照先が消えるのでは意味がない。

| ファイル | 参照元 | 内容 |
|---|---|---|
| `t8_t9_reverted.patch` | DEVLOG T-8 / T-9 | 採用しなかった停止検出と探索時間の変更。同じ症状が再発したときの出発点 |
