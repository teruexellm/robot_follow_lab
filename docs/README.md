## spec-v2.0.txt

**この実装が満たすべき要求の出どころ。** 実装の判断に迷ったときの基準は
README ではなくこの文書である。

節は `# N. 見出し` の形で、コードとドキュメントの `spec §60` のような参照は
その節番号を指す。参照は 629 件あり、実在する節を指しているかを
`scripts/check_spec_refs.py` が `make test` で検査する。

**凍結版である。** 実装を変えるときにこの文書を書き換えるのではなく、
差分を DEVLOG の「spec v2.0 との差分（全 73 節の照合）」に記録する。
仕様と実装がずれた理由が残らないと、どちらが正しいのか後から判断できない。
